# 애플 아카데미 지원 데이터 클리닝 사양

> DataWizard가 만들어 내야 하는 결과물의 기준 문서. 규칙이 바뀌면 이 문서와 코드를
> 함께 갱신한다. 공식 매핑표는 `MappingPresets.swift`에 내장되어 있다.

## 1. 원본 데이터(Raw Data)

### 1.1 일반 지원
- 애플 아카데미 홈페이지 ‘지원하기’로 접수 · 포트폴리오(CV) 업로드 **필수** · 로빈 관리
### 1.2 간편 지원
- 서술형 문항만 제출 · 포트폴리오(CV) **선택** · Wix 폼 접수 · 그웬 관리
- **Public**: 행사 참가자 대상, 소속 구분 없이 QR로 지원
- **Private**: 대학 홍보 행사 후 해당 대학 학생만 별도 QR로 지원

## 2. 데이터 관리

### Step 1. 데이터 클리닝
1. **일반 지원**: `Process Status == "Submitted"` 만 필터링
2. **간편 지원 통합**: Public + Private → 하나로
3. **전화번호**: 국내 `010-XXXX-XXXX` 통일, 해외는 원본 유지
4. **지원 방식 열 추가**: 일반 / 간편지원(Public) / 간편지원(Private)
5. **중복 제출자**: 전화번호·이메일을 Key로 (일반 내부 / 간편 내부 / 일반↔간편) 확인,
   중복은 별도 열에 "중복건" 표시, 서류 검토용은 **최종 제출 시간이 가장 최근** 건 유지

### Step 2. 데이터 통합 (일반 지원 포맷 기준)
1. 일반 지원 양식 기준으로 통합 (간편을 일반 양식에 맞게 가공)
2. **Unique ID**: 간편 지원엔 없으므로 규칙 생성 — 예 `6F10001`, `6F10002`… (6기 F1)
3. **이름**: 한글은 `성+이름`, 영어는 `이름 + 공백 + 성`
4. **생년월일**: `YYYY-MM-DD`
5. **만 나이**: 내년 3월 1일 기준, **만 19세 미만은 서류 검토 제외**
6. **성별**: 일반 양식 영문 표기
7. **Current City**: 간편 도시명 영문 변환. 해외 거주 → 간편은 실제 도시(London 등),
   일반은 `Current City = Overseas` + `City(Overseas)`에 실제 도시
8. **Current Country**: 영문 변환, 대한민국 외 → Overseas
9. **Current Status**: 일반 양식 영문 값으로 변환. **빈 값은 고교 재학 가능성 → 수기 확인**
   - 간편: 대학(원) 재학·휴학·졸업예정이 아니면 "그 외" / 풀타임·무직 등 별도 항목
   - 학교·회사 정보 구조 차이는 아래 표 참고
10. **서술형 답변 병합** (간편)
11. **CV/포트폴리오 링크 병합** (간편, 옵셔널 → 일반 링크 열 형식)
12. **Foundation Program**: 미참여 응답 삭제, 참여 시 `Apple Foundation Program @ POSTECH` 또는 수료 프로그램명
13. **How did you hear about our program?** 열 추가 (간편에만 존재)
14. **어떤 SNS였나요?** 열 추가 (간편에만 존재)
15. **Submitted At** 병합
16. **Level of Education**: 간편 "최종 학력" → 일반 양식 영문. 빈 값은 High/Middle School 확인 필요
17. **범위 제외**: 행사 참가 여부 · 온테스트 점수 · 기타 후속 데이터 (클리닝 후 별도 작업)
